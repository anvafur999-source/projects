# **Вкладка 1: «Основные показатели»** {#вкладка-1:-«основные-показатели»}

Данная вкладка предназначена для быстрого анализа ключевых бизнес-метрик маркетплейса: выручки, среднего чека, количества заказов и конверсии.

## **Блок «Выручка»** {#блок-«выручка»}

### **Выручка (GMV)** {#выручка-(gmv)}

**Что показывает:** Общую сумму продаж за выбранный период (Gross Merchandise Value).

**Как использовать:**

* Оценивайте общий масштаб бизнеса.  
* Сравнивайте показатели по месяцам.  
* Анализируйте рост или падение выручки.

###  **Динамика выручки (GMV)** {#динамика-выручки-(gmv)}

**Что показывает:** Изменение выручки по месяцам.

**Как использовать:**

* Отслеживайте сезонность.  
* Определяйте периоды ускоренного роста.  
* Выявляйте аномалии (резкие падения или всплески).

📌 Если рост выручки ускоряется — стоит проверить:

* рост числа заказов,  
* изменение среднего чека,  
* маркетинговую активность.

## **Блок «Средний чек»** {#блок-«средний-чек»}

### **Средний чек** {#средний-чек}

**Что показывает:** Среднюю сумму одного заказа за период.

**Формула расчёта:** Выручка / Количество заказов

**Как использовать:**

* Оценивать поведение покупателей.  
* Понимать, насколько эффективно работают upsell и кросс-продажи.  
* Анализировать изменение покупательской способности.

###  **Динамика среднего чека** {#динамика-среднего-чека}

**Что показывает:** Изменение среднего чека по месяцам.

**Как использовать:**

* Определять влияние акций и скидок.  
* Видеть рост премиальных покупок.  
* Анализировать изменение структуры корзины.

📌 Если выручка растёт, а чек стабилен — значит растёт количество заказов.  
📌 Если чек растёт — клиенты начинают тратить больше.

## **Блок «Заказы»** {#блок-«заказы»}

### **Количество заказов** {#количество-заказов}

**Что показывает:** Общее количество оформленных заказов за период.

**Как использовать:**

* Оценивать операционную нагрузку.  
* Анализировать рост активности покупателей.  
* Сравнивать динамику с выручкой.

### **Динамика заказов** {#динамика-заказов}

**Что показывает:** Изменение количества заказов по месяцам.

**Как использовать:**

* Определять периоды повышенного спроса.  
* Оценивать влияние маркетинговых кампаний.  
* Анализировать рост базы клиентов.

## **Блок «Конверсия»** {#блок-«конверсия»}

### **Конверсия** {#конверсия}

**Что показывает:** Процент посетителей, совершивших покупку.

**Формула расчета:** Количество покупателей / Количество посетителей × 100%

**Как использовать:**

* Оценивать эффективность сайта.  
* Анализировать качество трафика.  
* Определять узкие места в воронке продаж.

### **Динамика конверсии** {#динамика-конверсии}

**Что показывает:**  Изменение конверсии по времени.

**Как использовать:**

* Отслеживать влияние изменений интерфейса.  
* Анализировать влияние маркетинга.  
* Определять ухудшение пользовательского опыта.

📌 Если трафик растёт, а конверсия падает — вероятно, привлекается менее качественный трафик.  
📌 Если конверсия растет — улучшается пользовательский путь.

# **Как работать с вкладкой** {#как-работать-с-вкладкой}

1. Выберите нужный период анализа (если предусмотрены фильтры).  
2. Начните с блока «Выручка» — это главный показатель.  
3. Затем проанализируйте:  
   * Средний чек  
   * Количество заказов  
   * Конверсию  
4. Сопоставьте динамики между собой для поиска причинно-следственных связей.

# **Вкладка 2: «Аналитика продаж»** {#вкладка-2:-«аналитика-продаж»}

Вкладка предназначена для анализа структуры пользователей, активности товаров и структуры продаж  Позволяет понять, кто покупает, что продается лучше всего и как пользователи взаимодействуют с товарами.

# **Блок «Пользователи»** {#блок-«пользователи»}

## **Количество покупателей** {#количество-покупателей}

**Что показывает:** Общее число уникальных пользователей, совершивших покупки.

**Как использовать:**

* Оценивать масштаб клиентской базы.  
* Отслеживать рост числа покупателей.  
* Сравнивать с количеством продавцов.

## **Количество продавцов** {#количество-продавцов}

**Что показывает:** Общее число активных продавцов на платформе.

**Как использовать:**

* Оценивать масштаб предложения товаров.  
* Контролировать баланс маркетплейса.  
* Анализировать рост базы продавцов.

📌 Важно: Если продавцов растет быстрее покупателей — может возникнуть избыток предложения. Если покупателей больше — маркетплейс растёт устойчиво.

##  **Динамика продавцов и покупателей** {#динамика-продавцов-и-покупателей}

**Что показывает:** Изменение количества продавцов и покупателей по времени.

**Как использовать:**

* Отслеживать рост маркетплейса.  
* Понимать, какая сторона растёт быстрее.  
* Анализировать эффективность привлечения пользователей.

# **Блок «Товары»** {#блок-«товары»}

## **Количество отзывов** {#количество-отзывов}

**Что показывает:** Общее количество оставленных отзывов о товарах.

**Как использовать:**

* Оценивать вовлечённость покупателей.  
* Анализировать доверие к платформе.  
* Понимать активность после покупки.

## **Среднее количество позиций в заказе** {#среднее-количество-позиций-в-заказе}

**Что показывает:** Среднее число товаров в одном заказе.

**Как использовать:**

* Оценивать размер корзины.  
* Анализировать кросс-продажи.  
* Понимать глубину покупки.

📌 Рост показателя означает:  
 покупатели чаще берут несколько товаров сразу.

## **Среднее количество слов в отзыве** {#среднее-количество-слов-в-отзыве}

**Что показывает:** Среднюю длину пользовательских отзывов.

**Как использовать:**

* Оценивать качество обратной связи.  
* Анализировать вовлеченность клиентов.  
* Понимать глубину пользовательских отзывов.

# **Вкладка 3: «Аналитика пользователей»** {#вкладка-3:-«аналитика-пользователей»}

Вкладка предназначена для анализа поведения пользователей, их вовлеченности и ценности для бизнеса.  
Помогает понять, как пользователи возвращаются, сколько приносят дохода и насколько активно используют платформу.

# **Блок «Вовлечённость пользователей»** {#блок-«вовлечённость-пользователей»}

## **DAU (Daily Active Users)** {#dau-(daily-active-users)}

**Что показывает:**  
 Количество активных пользователей (покупателей) в день.

**Как использовать:**

* Оценивать ежедневную активность пользователей.

* Отслеживать рост аудитории.

* Анализировать влияние маркетинга и акций.

* Сравнивать активность по времени.

📌 Рост DAU \= рост интереса к платформе.  
 📌 Резкие падения могут говорить о технических проблемах или снижении трафика.

## **Retention rate (удержание пользователей)** {#retention-rate-(удержание-пользователей)}

**Что показывает:** Процент пользователей, которые возвращаются на платформу повторно.

Отображается в виде тепловой карты по когортам.

**Как использовать:**

* Оценивать удержание новых пользователей.  
* Понимать, как быстро пользователи «отваливаются».  
* Анализировать качество продукта и сервиса.  
* Сравнивать когорты пользователей по месяцам.

📌 Высокий retention \= пользователи возвращаются.  
 📌 Низкий retention \= проблемы с ценностью продукта или UX.

# **Блок «Монетизация»** {#блок-«монетизация»}

## **LTV (Lifetime Value)** {#ltv-(lifetime-value)}

**Что показывает:** Средний доход, который приносит пользователь за всё время взаимодействия с платформой.

**Как использовать:**

* Оценивать ценность клиента.  
* Сравнивать с затратами на привлечение.  
* Определять прибыльность маркетинга.  
* Анализировать долгосрочный рост.

📌 Если LTV растёт — пользователи тратят больше со временем.  
📌 Падение LTV может говорить о снижении качества аудитории.

## **ARPU и ARPPU** {#arpu-и-arppu}

### **ARPU (Average Revenue per User)** {#arpu-(average-revenue-per-user)}

Средняя выручка на одного пользователя.

### **ARPPU (Average Revenue per Paying User)** {#arppu-(average-revenue-per-paying-user)}

Средняя выручка на платящего пользователя.

**Что показывает:** Сколько в среднем приносит один пользователь и один покупатель.

**Как использовать:**

* Оценивать эффективность монетизации.  
* Понимать качество аудитории.  
* Сравнивать периоды.  
* Анализировать влияние акций и цен.

📌 Если ARPU растёт — пользователи тратят больше.  
📌 Если ARPPU растёт — платящие клиенты становятся ценнее.

#  **Как анализировать вкладку** {#как-анализировать-вкладку}

Рекомендуемый порядок анализа:

1. Посмотреть DAU → понять активность.  
2. Проверить Retention → удерживаются ли пользователи.  
3. Проанализировать LTV → сколько приносит пользователь.  
4. Сравнить ARPU и ARPPU → качество монетизации.

# **Что позволяет понять вкладка** {#что-позволяет-понять-вкладка-1}

* Возвращаются ли пользователи  
* Растёт ли активная аудитория  
* Сколько приносит один пользователь  
* Насколько эффективна монетизация  
* Улучшается ли удержание клиентов
